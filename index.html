Sauvegarde Firebase

Colle uniquement l’URL de ta Realtime Database. Exemple : https://mon-projet-default-rtdb.europe-west1.firebasedatabase.app

Les données sont rangées séparément dans users/nom-du-compte. NOVA conserve aussi une copie locale sur cet appareil.

Règles Realtime Database

Ces règles autorisent la lecture et l’écriture sans connexion. C’est pratique pour un test, mais toute personne connaissant l’URL pourra lire, modifier ou supprimer les données. Ne stocke aucune information privée et ne laisse pas ces règles ainsi pour un usage réel.

{
  "rules": {
    ".read": true,
    ".write": true
  }
}
